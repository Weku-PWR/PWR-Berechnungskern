PFEIL Wochenrapport 2.1.1 - Windows-Programm erstellen

Voraussetzungen fuer einen lokalen Build:
- Windows 10 oder 11
- Node.js 22 mit npm
- Git-Arbeitskopie dieses Repositorys

Lokaler, reproduzierbarer Build:
1. In PowerShell in das Repository wechseln.
2. Abhaengigkeiten exakt aus package-lock.json installieren:
   npm ci
3. Vollstaendigen Windows-Build starten:
   npm run dist:win
   Vor dem Build laufen automatisch Syntaxpruefung, Katalogpruefung und alle Tests.
4. Die auszuliefernden Dateien liegen danach unter dist\release:
   - PFEIL-Wochenrapport-Setup-2.1.1-x64.exe
   - PFEIL-Wochenrapport-Portable-2.1.1-x64.exe
   - PFEIL-Wochenrapport-Windows-2.1.1-x64.zip
   - SHA256SUMS.txt

Build mit GitHub Actions:
1. Im GitHub-Repository "Actions" oeffnen.
2. Den Workflow "Windows-Programm erstellen" waehlen.
3. "Run workflow" anklicken. Bei Pull Requests und bei Pushes auf main startet er automatisch.
4. Warten, bis alle Schritte erfolgreich sind: npm ci, Syntaxpruefung, Tests,
   Katalogpruefung, Build-Vorpruefung und Windows-Build.
5. Im abgeschlossenen Lauf unter "Artifacts" das Artefakt
   "PFEIL-Wochenrapport-Windows-2.1.1-x64" herunterladen.
6. Das GitHub-Artefakt entpacken. Es enthaelt die vier oben genannten Dateien.
7. Vor der Weitergabe die SHA-256-Werte pruefen, zum Beispiel in PowerShell:
   Get-FileHash .\PFEIL-Wochenrapport-Setup-2.1.1-x64.exe -Algorithm SHA256
   Die Ausgabe muss zum entsprechenden Eintrag in SHA256SUMS.txt passen.

Hinweis zu Windows SmartScreen:
Die Programme sind noch nicht mit einem kostenpflichtigen Code-Signing-Zertifikat signiert.
Windows kann deshalb "Windows hat den PC geschuetzt" anzeigen.
Dann "Weitere Informationen" und "Trotzdem ausfuehren" waehlen, sofern die Datei
direkt aus dem eigenen GitHub-Build stammt und die SHA-256-Pruefsumme stimmt.
