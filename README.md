# PWR Berechnungskern 2.0.2

Korrigierte GitHub-Pages-Testversion für die fachliche Freigabe der Stundenberechnung.

## Aktualisierung im bestehenden Repository

1. Dieses ZIP entpacken.
2. GitHub-Repository `PWR-Berechnungskern` öffnen.
3. **Add file → Upload files** wählen.
4. Alle Dateien und Ordner aus diesem Paket hochladen.
5. Vorhandene Dateien überschreiben und **Commit changes** wählen.
6. Zwei bis fünf Minuten warten.
7. Die veröffentlichte Seite öffnen und mit **Strg + F5** aktualisieren.
8. Oben muss **Version 2.0.2** stehen.

## Wichtigste Korrektur

- Beginnt die Rapportzeile am Samstag oder Sonntag, läuft Sonntagsarbeit bis Montag 06:00 Uhr weiter.
- Beginnt die Rapportzeile am Montag 00:00 Uhr, gilt sofort Wochentag Nacht; ab 06:00 Uhr Wochentag Tag.
- Ein manuell markierter Feiertag gilt für die gesamte Rapportzeile.

## Installation als App

In Microsoft Edge: Menü `…` → **Apps** → **Diese Website als App installieren**. Falls dieser Punkt nicht erscheint, Seite nach dem Upload mit Strg+F5 neu laden und einige Sekunden warten.
