# PFEIL Wochenrapport 2.1.0

Dieses Repository erzeugt über GitHub Actions ein installierbares Windows-Programm und eine portable EXE.

## Windows-Build

`Actions` → `Windows-Programm erstellen` → Artefakt herunterladen.

## Aktueller Funktionsumfang

- Berechnung im 15-Minuten-Takt
- Aufteilung Wochentag/Sonn- und Feiertag sowie Tag/Nacht
- Samstagregel ab 17:00 Uhr
- Sonntag-zu-Montag-Regel
- manuelle Feiertagskennzeichnung
- nachvollziehbarer Rechenweg
- automatisierter Testkatalog

Die vollständige Rapportmaske wird auf diesem geprüften Berechnungskern aufgebaut.
