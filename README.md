# PWR Berechnungskern 2.0.1

GitHub-Pages-fertige Testversion für den Benutzer **Weku-PWR**.

## Veröffentlichung auf GitHub Pages

1. Bei GitHub anmelden.
2. Oben rechts **+** → **New repository**.
3. Repository-Name: `pwr-berechnungskern`
4. Sichtbarkeit: **Public**.
5. **Create repository** wählen.
6. Auf der Repository-Seite **uploading an existing file** wählen.
7. Sämtliche Dateien und Ordner aus diesem entpackten Paket hochladen.
8. **Commit changes** wählen.
9. Im Repository **Settings** → **Pages**.
10. Unter **Build and deployment**: Source = **Deploy from a branch**.
11. Branch = `main`, Ordner = `/ (root)`, danach **Save**.

Nach einigen Minuten lautet die Adresse voraussichtlich:

`https://weku-pwr.github.io/pwr-berechnungskern/`

## Installation unter Windows

1. Adresse in Microsoft Edge oder Chrome öffnen.
2. Browsermenü öffnen.
3. **Apps** → **PWR Berechnungskern installieren** beziehungsweise das Installationssymbol in der Adresszeile wählen.
4. Die App erscheint danach im Startmenü und kann wie ein Programm geöffnet werden.

## Wichtige Rechenregeln

- 15-Minuten-Intervalle ausschliesslich 00, 15, 30, 45.
- Tag 06:00–20:00.
- Nacht 20:00–06:00.
- Samstag ab 17:00 gilt als Sonn-/Feiertagsarbeit.
- Sonntag gilt vollständig als Sonn-/Feiertagsarbeit.
- Ein manuell markierter Feiertag gilt für die gesamte Rapportzeile.
- Beginn = Ende ist ungültig.
- Samstag und Sonntag werden beim Wochentag rot dargestellt.
